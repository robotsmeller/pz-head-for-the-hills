# Head for the Hills!

A start-scenario mod for Project Zomboid Build 42. Your survivor saw it coming and got out ahead of the outbreak, up to a remote cabin. You start there: stocked with basic supplies, a vehicle nearby, and no zombies for a stretch around the property. The nearest town is still a drive away if you want to push your luck.

**Status: early scaffold. No gameplay content yet.**

## Planned

- Custom spawn region: 2-3 hand-picked existing rural cabins, chosen at random per game start
- Starting kit: basic survival supplies via a dedicated trait/occupation
- A vehicle spawned near the cabin
- A zombie-free buffer immediately around the starting cabin
- Real drivable distance to an existing town for anyone who wants to go back in

## Requirements

- Project Zomboid Build 42.20.0+

## Install

Not yet published. Once a build exists: copy `mod/` into `Zomboid/mods/HeadForTheHills`, or subscribe via Steam Workshop (link TBD).
